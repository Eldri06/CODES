## 📖 About

**CODES System** is a desktop-based application designed to manage products and administrative workflows through an intuitive graphical user interface. It provides multiple forms for handling product details, user profiles, and system operations, with a dedicated admin dashboard for monitoring.

---

## ✨ Features

**📦 Product Management**
- View product listings  
- Display detailed product information  
- Add and manage products through admin interface  

**🧑‍💼 Admin Dashboard**
- Centralized control panel for system management  
- Access to product and user-related operations  
- Organized interface for administrative tasks  

**👤 User Interface**
- Profile management functionality  
- Interactive forms for navigation  
- Custom message boxes for better user feedback  

**🖥️ Multi-Form Navigation**
- Landing page for entry point  
- Separate forms for product details and profile  
- Structured UI flow using Windows Forms
